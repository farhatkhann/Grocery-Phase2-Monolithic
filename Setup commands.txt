2. npm install tree-sitter tree-sitter-javascript

3. Create a file run-parser.js in the project root or src
   How this works?
   readAllFiles() recursively finds .js/.jsx/.ts/.tsx files under        src/.

   For each file, we parser.parse(src) to get a Tree.

Result is saved to api-sementics.json in your project root.
Annotations = Semantic Labels extracted from code automatically

4. Install CodeT5+
   npm install @xenova/transformers

5. Create a file sementic-analyzer.mjs

Tree-Sitter Parser → JSON (structural info) → CodeT5+ → semantic-extraction.json

6. Ontology File named as build-ontology.py

Requirements: 
python version 3.8+
python -m pip install rdflib

To run the file:
python build_ontology.py

Install Protégé to view the owl/ttl extracted files.

7. Graph Based Sementic Extraction
Create file named as:
i. static-graph.py based on api-sementics.json
ii. sementic-graph.py based on sementic-extraction.json

Install: pip install networkx rdflib matplotlib

Run: 
python semantic-graph.py
python static-graph.py
